# HTTP Basic Auth 支持 — 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 OSB 自动化工具生成的 Business Service 包含 HTTP Basic Authentication 配置，以支持 SAP 等需要密码校验的接口。

**Architecture:** 在 `endpoint` 配置段增加 `username`/`password` 可选字段，Jinja2 模板有条件渲染 `<http:authentication>` XML 段。3 个文件改动：模板、后端配置收集、前端表单。

**Tech Stack:** Jinja2 模板引擎 + Flask Web 应用 + 纯 HTML/CSS/JS 前端

---

### Task 1: 修改 Business Service 模板 — 增加认证段渲染

**Files:**
- Modify: `templates/jinja2/business_service_http.bix.j2:43-44`（在 `</http:outbound-properties>` 和 `<http:dispatch-policy>` 之间）

**背景:** 当前模板第 43 行是 `</http:outbound-properties>` 闭合，第 44 行是 `<http:dispatch-policy>`。需要在它们之间插入认证段。

- [ ] **Step 1: 在模板中插入认证段**

在 `templates/jinja2/business_service_http.bix.j2` 第 43 行 `</http:outbound-properties>` 之后、第 44 行 `<http:dispatch-policy>` 之前，插入：

```jinja2
            </http:outbound-properties>
{% if endpoint.username %}
            <http:authentication>
                <http:basic-authentication>
                    <http:username>{{ endpoint.username }}</http:username>
                    <http:password>{{ endpoint.password }}</http:password>
                </http:basic-authentication>
            </http:authentication>
{% endif %}
            <http:dispatch-policy>
```

注意缩进：XML 内容用 12 个空格（3 层），与周围 `<http:...>` 标签对齐。

- [ ] **Step 2: 验证模板文件**

读取 `templates/jinja2/business_service_http.bix.j2` 确认：
- `</http:outbound-properties>` 后紧跟认证段
- `<http:dispatch-policy>` 在认证段之后
- 缩进与上下文一致（12 空格）
- `{% if %}` 和 `{% endif %}` 在行首
